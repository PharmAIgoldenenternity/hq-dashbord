# HQ Dashboard 协作说明

## 项目定位

这是一个本地静态个人仪表盘网站，目录位于：

- `C:\Users\39550\OneDrive\hq-dashboard`

目标是把高质量信息入口、今日重点、专注计时和提醒集中到一个安静的首页里。

## 技术边界

- 保持纯静态：`HTML + CSS + JavaScript`
- 不要默认引入框架、打包器、状态库或后端
- 不要把外部站点嵌入页面；保持“点击后直接打开真实页面”的行为
- 内容优先通过 `data/site-data.js` 维护，而不是把内容写死到多个文件

## 文件职责

- `index.html` — 页面骨架与区块容器
- `styles.css` — 所有视觉风格、布局、响应式规则
- `app.js` — 页面渲染、计时器、聚焦模式等轻交互逻辑
- `data/site-data.js` — 标题、分类、链接、提醒语、说明文字等内容数据
- `fonts/` — 本地托管的字体文件；当用户明确指定具体字体时，优先用 `@font-face` 加载真实字体文件，而不是只找近似系统字体

## 字体与视觉约束

- 用户对字体分类和历史脉络较敏感；不要把“相似气质”当作“正确字体”
- 当用户点名某个具体字体家族（例如 Copperplate、Snell Roundhand）时，优先确认是具体字体文件、具体分支，还是仅仅参考该风格
- 如果页面要稳定呈现某款展示字体，优先把字体文件放进 `fonts/` 并在 `styles.css` 中通过 `@font-face` 引入

## 修改原则

- 优先编辑现有四个文件，不要轻易拆成更多结构
- 视觉优化应优先通过颜色、留白、排版和层级完成，而不是增加装饰组件
- 小功能如果没有明确需要，不要扩展成复杂系统
- 维持页面安静、克制、可快速扫描的风格
- 改 UI 时，尽量保留当前已有功能区和直达链接行为

## 常见任务路由

- 替换常用网站、分类、提醒语：改 `data/site-data.js`
- 优化 Apple 风格、字体、卡片、按钮、留白：改 `styles.css`
- 调整区块标题与页面结构：改 `index.html`
- 调整计时器或聚焦模式：改 `app.js`

## 验证重点

- 页面可直接本地打开
- 所有链接仍能正确跳转
- 计时器开始、暂停、重置正常
- 聚焦模式仍可切换
- 修改数据文件后刷新页面即可生效
