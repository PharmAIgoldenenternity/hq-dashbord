# 高质量信息仪表盘

这是一个本地静态网站，用来把你每天最常用、最重要的信息入口集中到一个安静的首页里。

## 项目目标

这个网站的重点不是抓取信息，而是：

- 把高质量信息源放到一个统一入口
- 保留今日重点、专注计时和提醒
- 让你每天先进入真正重要的页面，而不是随机刷内容

## 当前结构

- `index.html` — 页面结构
- `styles.css` — 视觉样式
- `app.js` — 页面渲染与交互逻辑
- `data/site-data.js` — 可编辑的数据源

## 如何使用

直接打开以下文件即可：

- `C:\Users\39550\OneDrive\hq-dashboard\index.html`

也可以通过桌面快捷方式打开。

## 如何修改内容

如果你想调整网站里的站点、分类、提醒语或首页文案，优先修改：

- `data/site-data.js`

如果你想调整布局、配色、字体、卡片样式或整体视觉，主要修改：

- `styles.css`
- `index.html`
- `app.js`

## 当前设计原则

- 保持静态 HTML/CSS/JS，不引入框架
- 所有链接直接打开真实目标页面
- 默认保留简洁、安静、低噪音的视觉风格
- 优先做易维护的小改动，不为未来假想需求过度设计
